🎯 Frontend Components Breakdown
Component	Description
Header Bar	App title, submit/save buttons
Sidebar	Draggable node types (Input, Text, LLM, Output, etc.)
Canvas Area	Main area with ReactFlow canvas for connecting nodes
Submit Button	Sends data to backend (/pipelines/parse)
Toast/Alert	Shows result like: "Nodes: 4

Enter content (e.g., Hello {{user}})
